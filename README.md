An entry for the make.fun bounty "Alien Field Notes: The Two Day Earth Review". The program writes a single original one-line review of planet Earth, left by an alien tourist after two days on the planet: nobody on Earth asked which galaxy it came from, but three strangers read its personality off the month it was born — 4/5 stars, would abduct again. It runs on Node 22 with the standard library only, reads `MAKEFUN_OUTPUT_DIR` (default `/output`), and writes the review to `entry.txt`.
